# Roadmap

## Abgeschlossen

- Phase 1: Repo, Basisscaffold, Dokumentation, Test-Setup, erste Produktoberflaeche, erster Vercel-Deploy
- Phase 2: Prisma-Schema, lokale Migration, Seed-Daten, Kernlogik fuer Margin, Snapshot und Delta

## Als Naechstes

1. Phase 3: Auth.js, Rollenmodell, Memberships, Guards, geschuetzte Bereiche
2. Phase 4: Manager-Portal mit CRUD-Flows, Snapshot-Publishing, Historie, Tests
3. Phase 5: Tenant-Portal mit Transparenzansicht, Servicefaellen, Dokumenten, Mitteilungen, Tests
4. Phase 6: E2E-Finalisierung, Demo-Polish, Vercel-Deploy, Restdokumentation

## Qualitaetsfokus

- Keine neue Fachlogik ohne Tests
- Jede Phase bleibt deploybar
- Dokumentation bleibt synchron zum Implementierungsstand
