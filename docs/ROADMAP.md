# Roadmap

## Abgeschlossen

- Phase 1: Repo, Basisscaffold, Dokumentation, Test-Setup, erste Produktoberflaeche, erster Vercel-Deploy
- Phase 2: Prisma-Schema, lokale Migration, Seed-Daten, Kernlogik fuer Margin, Snapshot und Delta
- Phase 3: Credentials-Login, Rollengrenzen, geschuetzte Portalrouten, seed-basierte Portalabfragen
- Phase 4: Manager-Portal mit API-Mutationen, Objekt-/Einheitsverwaltung, Lease-Steuerung, Snapshot-Publishing, Servicefall-Status und Tests

## Als Naechstes

1. Phase 5: Tenant-Portal mit Transparenzansicht, Servicefaellen, Dokumenten, Mitteilungen, Tests
2. Phase 6: E2E-Finalisierung, Demo-Polish, Vercel-Deploy, Restdokumentation
3. Cloud-DB plus produktnahe Vercel-Authentifizierung fuer den Online-Login

## Qualitaetsfokus

- Keine neue Fachlogik ohne Tests
- Jede Phase bleibt deploybar
- Dokumentation bleibt synchron zum Implementierungsstand
